## 2. 固定划分与重复检查

`src/vdcp/splits.py:7–27` 的实际实现为：按原图内容的 SHA256 分组；每组取四类存在标签的并集；用迭代多标签分层随机划分，第一步按 70%/30% 分出训练与待分配组，随机种子 **20261008**；第二步在后者中 50%/50% 分为 val/test，随机种子 **20261009**。这相当于目标 70%/15%/15%，按组操作和整数分配使图像比例有轻微差异。先分原图，再裁窗。

本次直接调用原 `create_splits` 复现，得到的逐图分配与现有三个 CSV **完全一致**。三个清单图像 ID 两两交集均为 0，并集等于原 manifest，未丢图、未重复分配；manifest 的 12,568 个 ID 唯一。按 manifest 已有 SHA256 检查，精确重复内容组为 0，跨划分 SHA256 组为 0。

重复检查的边界：本次核对的是 manifest 中已记录的图像 SHA256，没有重新读取并散列全部 JPEG，也没有进行近重复或同一钢板来源分组识别。因此不能据此宣称排除了近重复、相邻帧或来源层面的关联。
